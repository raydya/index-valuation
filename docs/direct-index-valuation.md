# 指数直接估值与网页

指数配置驱动采集、存储、计算和网页，不依赖成分、权重或公司 EPS。下文富途方法 `futu_index_implied_v1` 适用于支持富途的内地/香港指数；富途未收录的红利低波使用中证官方方法，美股采用独立主源与方法版本，分别见下文。算法不按指数名称分支。

## 数据与计算

- 富途 `request_history_kline(AuType.NONE)` 提供日收盘点位；`get_valuation_detail` 分别请求 PE、PB、PS 和 YEAR_30，保留全部原始响应及元数据。
- 中证指数、国证指数历史 `close`、BaoStock 日线、东方财富未复权日线核验点位。富途方法按富途、中证、国证、BaoStock、东方财富的顺序选择可用点位；只请求配置适用的独立来源，需要另一来源同日核验通过才推导 EPS。相差1%—5%保留 warning，超过5%或没有参照价格则不生成 EPS。中证官方主源方法采用下文的官方优先规则。
- 富途 PE 为唯一主 PE 序列，缺失和零值不从中证替换。中证滚动 PE 单独保存和比较。PB、PS 保存为富途原始估值，目前未独立核实其财务口径。
- 所有来源按交易日历过滤；周末、节假日等异常源记录保留在原始文件，并写入隔离报告，不移动日期。日线日期不得在尚未收盘的未来。

```text
隐含 EPS[t] = 同日指数收盘点位[t] / 富途指数 PE[t]
固定倍数点位[t, m] = 隐含 EPS[t] × m
平均 PE[t] = 此前窗口内同源每日正 PE 的算术平均
平均 PE 对应点位[t] = 隐含 EPS[t] × 平均 PE[t]
历史分位点位[t, q] = 隐含 EPS[t] × quantile(此前同源正 PE, q)
```

隐含 EPS 的单位是指数点。指数 PE 的盈利期、加权及亏损处理仍未完整确认，因此不写成 EPS TTM。反算 EPS 不构成对 PE 的独立财报审计，band 表示指定倍数下的参考点位。

## 历史平均 PE 与分位

统计窗口默认5年，可选3年、5年、10年及全部历史，同时控制平均 PE 和分位，与图表展示区间独立。日历年窗口左端包含、右端严格小于当天。2月29日回退到对应年的2月28日。每个历史日期均重新使用自己的当时窗口，不能用今天的平均 PE 或分位阈值画整段历史。

平均 PE 对每个有效交易日等权，保留极端正值，不截尾。至少252个历史样本才展示均值。图中虚线在点位视图表示当日隐含 EPS × 当时的历史平均 PE，在 PE 走势视图直接表示历史平均 PE。均值可在当日缺少价格或 EPS 时显示，此时对应点位留空。它衡量指数自身历史估值，不计算成分股 PE 的横截面平均。

当最早可用正 PE 晚于统计窗口左端时，`history_span_short` 标为 true，网页提示“历史不足N年”并展示实际样本范围。统计仍按已有有效样本计算，不补齐缺失年份。例如新发布指数虽有多年回溯点位，未必有同样长的 PE 历史。该标记只描述可用历史跨度，不代表已经检查每个交易日的完整性。

有效样本为同一富途口径的正 PE，即使那天缺价格，也可贡献 PE 分布。至少252个历史样本才展示分位。分位阈值使用线性插值（位置 `(n-1)q`）；当前分位使用 `(小于当前值的数量 + 等于当前值的数量/2) / n × 100%`。负 PE / EPS 保留，但不生成正倍数 band 或当前百分位。历史窗口包括接口提供的发布前回溯 PE，网页逐日标记其性质。

历史 PE 与中证差异超过5%的记录仍显示为富途自身口径的原始估值，并显式标记来源差异和口径未核实；不称为已验证的官方 PE。两家口径不同的序列不混合计算分位。供应商可能修订历史；排除未来日期不意味着具备当年已公开、未经事后修订的 point-in-time 财务数据。

## 年化收益

网页顶部的年化收益跟随**图表展示区间**（1/3/5/10年、全部），与 PE 统计窗口独立。回看历史日期时，只使用该日期及之前的收盘点位；在区间内取首末实际可用价格，页面显示实际起止日期，不向区间边界补值。价格历史短于所选年限时，以实际跨度计算，不假设已有完整年限。

```text
年化收益（%）= [(期末点位 / 期初点位) ^ (365.25 / 实际相隔自然日数) - 1] × 100
```

这是价格指数的复合年化涨幅，**不含分红**、交易费用及汇率换算，不是把累计涨幅除以年数。使用 `Decimal` 计算，自然日包含周末、节假日和闰日。短于一年的区间按实际天数折算并提示；没有价格、只有一个价格日期或端点无效时留空。端点价格核验存在重大差异时通常留空；官方优先方法中已采用的有效官方点位可继续计算，保留差异并显示采用官方值的提示。单源价格可以计算，但显式显示端点未核验；包含发布前回溯数据时另作提示。

该指标不依赖 PE、EPS 或估值 band 是否可用，也不因美股 PE 的周采样删减价格日。计算实现在 `performance.py`，所有指数复用；不新增数据库字段或行情请求。dashboard API 的 `price_return` 返回年化与累计涨幅（单位均为百分数）、首末日期/点位/来源、实际天数及质量状态；逐日 CSV 中的对应端点可复核计算，CSV 不重复写入整个区间的汇总收益。

## 存储和更新

- `daily_observations`、`source_valuations`：原始点位和估值，保留来源、日期、文件路径。
- `index_series`：主键为指数、交易日、方法；保存选定点位、PE、隐含 EPS，以及 JSON 来源、PB/PS、核验状态、回溯标记。重复运行更新相同主键，保留原始响应和运行记录。
- `daily_valuations`：原有成分重算结果，完全独立，不写入直接指数结果。

`backfill-index` 默认从配置 `history_start_date`（缺省用 `inception_date`）到最近已收盘日期；`update-index` 从最后已入库日回退14天更新，长时间停机也会覆盖后续完整缺口。若富途指数已有价格但还没有任何 PE（例如首次缺少权限），增量命令仍保留完整回填起点，以便权限恢复后补齐历史。已知不支持富途的指数照常增量，切换 PE 主源时使用新方法版本触发首次回填；价格专用系列不反复全量请求。两个命令随后重新派生全部指数序列。更早修订通过全量刷新获取。`build-index` 仅从现有数据库重建。

采集与派生各有任务锁和运行记录。一个数据源失败时保留其他来源及已有数据，最终报告 `partial` 并附采集报告；不会把旧数据重命名成最新日期。`collected` 表示技术流程完成，不是财务口径验证结论。

内地交易日历优先从 BaoStock 获取；其不可用时，先复用完整覆盖请求区间的历史日历归档，校验 SHA-256、完整自然日标记、重复日期及观测时间。缓存不向未覆盖日期外推。近期增量超出缓存范围时可使用富途 A 股交易日历，保留独立来源与原始响应；富途只允许过去10年范围，临时休市不在其日历保证范围内。所有备用路径均记录原因，不隐瞒 BaoStock 故障。没有可用日历时终止采集，不按工作日猜测交易日。

香港使用富途 HK 市场日历，不使用 BaoStock 或内地假期。更早的香港日期使用富途恒生指数 `HK.800000` 实际日线的日期，保留基准代码和日线原始文件；这属于实际历史交易日期参照，不宣称是交易所完整日历。富途日历中误列为开市的2016-10-21、2017-08-23，依据港交所全日停市公告排除，修正日期与公告链接记入日历归档。香港按16:10后采集当日数据；半日市同样保守等待至此时间。HKD、CNY 分别保存，隐含 EPS 和 band 始终以各自指数点位计算，不需要汇率换算。

中证参考历史分年采集；个别年份 HTTP 请求失败时保留其他年份并记录 `failed_ranges`，来源标为 `partial`。连续3个请求失败则停止后续年份并记录尚未尝试区间。它不会使其他价格来源或富途估值丢失。

网页是只读 FastAPI 应用，使用数据库中的派生序列。HTML/CSS/JavaScript/SVG 全部随应用提供，不需要外部图表或字体 CDN，也不把数据库密码发送到前端。默认仅在 `127.0.0.1:8000` 监听；采集由命令行或已有定时任务运行。

接口：`GET /api/indices`、`GET /api/indices/{key}/dashboard`、`GET /api/indices/{key}/export.csv`。后两者接受 `as_of`、`chart_years` 和 `history_years`。非交易日选择解析为不晚于请求日的最后一个记录日；早于数据起点返回明确错误。CSV 使用 UTF-8 BOM，保存原始数值精度、来源和质量状态。`mean_pe`、`mean_points` 分别为历史平均 PE 与对应点位；`history_years`（0为全部历史）、`history_count`、`history_start`、`history_end` 保留统计窗口及实际样本范围。

## 中证官方 PE 主源

中证官方主源指数配置 `valuation_source = "csindex"`，复用中证日线适配器的 `peg`（官方滚动 PE），自2026-10-14起采用独立方法 `csindex_index_implied_daily_v2`。均值和分位使用同一官方口径的有效日度正 PE，最低252个历史观测；雪球基金历史周采样仅用于同日对照，不改变官方序列的日度采样，也不替补缺失 PE。

此方法以指数官方数据为准。官方点位优先于第三方点位；第三方价格或 PE 缺失、差异超过5%时，仍使用有效官方点位和同日官方 PE 计算隐含 EPS、band、百分位，官方 PE 也继续贡献后续统计。`price_status`、`pe_comparison_status` 保留真实对照状态，`price_usable`、`pe_usable` 单独表示计算资格，不把官方优先改写成核验通过。官方 PE 缺失、为零或非有限值时仍留空；官方点位缺失后的第三方备用点位仍要求独立核验。负 PE 保留隐含负 EPS，但不生成正倍数 band 或百分位。

中证不与自身作为第二来源比较；中证官方单张注明指数指标使用计算用股本，第三方 PE 的盈利、权重及亏损处理仍需分别核实。v1 的差异阻断结果保留在原方法下，v2 从全部已存输入重建，避免新旧规则混合或只修复最近14天。执行 `build-index --index divlowvol` 后重启网页加载新方法；后续增量自动沿用 v2。既有富途和美股替代主源方法仍分别保留自身口径。

`CSI.<官方代码>` 为无富途报价映射的中证指数内部标识，归入内地市场，必须显式配置东方财富代码并关闭富途报价。BaoStock 仅提供交易日历，不请求不支持的 CSI 命名空间日线；日历失败可使用已验证缓存或独立的富途市场日历连接，后者不请求该指数报价。不支持的来源标为 `unsupported`，实际请求失败标为 `failed`。当前红利低波使用 `H30269`、东方财富 `2.H30269`、雪球 `CSIH30269`，详见[接入记录](divlowvol-index-2026-10-13.md)。

## 美股来源与采样

美股指数身份、交易日历、价格和 PE 适配器通过配置选择。VOO 对应标普500、QQQ 对应纳斯达克100，VTI 对应 Morningstar US Total Market（原 CRSP US Total Market）。均使用价格回报指数点位、USD 和纽约时区，不引入 ETF 价格或全收益指数点位；用户授权的 ETF PE 代理规则如下。

标普500、纳指100现使用用户授权的 Yahoo SPY、QQQ ETF PE 代理，方法分别为 `yahoo_spy_proxy_fred_daily_v1`、`yahoo_qqq_proxy_nasdaq_daily_v1`。两者复用 `YahooETFValuation`，ETF 与指数身份通过显式映射校验。输入仍保存指数身份，来源标为 `yahooetf`，指标为 `pe_ttm_proxy`，口径包含代理 ETF 代码，原始记录另外保存 ETF 身份、采集时间和日期依据。

标普官方点位经 FRED 获取，纳指从 Nasdaq 官方接口获取；`price_sources` 限制为各自官方源和 Yahoo，`official_price_source` 指定采用值。Yahoo 只作同日价格核验，缺少对照或差异超过5%仍采用有效官方点位；官方点位缺失则保持为空。东方财富、纳指旧 FRED 以及旧 PE 记录虽保留在数据库，也不会参与新方法。FRED 的标普历史仅提供近10年，因此新方法的官方价格历史不等于旧 Yahoo 全历史。美国日历仍使用 NYSE 规则及纽约时区。

Yahoo 页面 `summaryDetail.trailingPE.raw` 提供当前 ETF PE 快照。仅关联 `regularMarketTime` 所属的已收盘交易日，PE 自身生效日未知，不能将行情日期称为 PE 确切生效日期。按原始 `Decimal` 入库，记录 `pe_date_basis` 和 `pe_observed_at`；盘中、未来、请求区间外、无有效正 trailing PE 的快照不生成估值。历史回填不会将当前 PE 复制到其他日期，旧雪球、其他 ETF、forward PE 和持仓收益率不会填充缺口。

代理隐含 EPS = 官方指数点位 / ETF 代理 PE；固定倍数 band 继续保留8倍。新代理逐日积累历史，均值和分位只使用估值日以前的同代理有效正 PE，至少252个观测。旧雪球恐慌研究保留原来源和阈值，因口径不同暂停比较与画线。导出 CSV 包含 ETF 代理身份、日期依据和采集时间，文件名带新方法名以保留旧导出。完整实现与运行结果见 [代理接入记录](yahoo-etf-proxy-2026-10-15.md)。

旧 `danjuan_index_implied_weekly_v1` 独立保留：雪球长历史为周采样，均值和分位每个已结束自然周最多取最后一个有效正 PE，最低52个周观测；不混入当前日度代理序列。

旧雪球方法仍保留同日 PE 对照差异超过5%时停用 EPS/band 和统计贡献的规则。新 ETF 代理没有已核实同口径的独立 PE 对照，不将旧指数 PE 强作校验，也不将采用代理写成财务口径已验证。

VTI 基准自2026-10-16采用 `yahoo_vti_proxy_yahoo_google_daily_v1`。PE 复用 `YahooETFValuation`，显式映射 VTI；点位采用 Yahoo `^CRSPTM1`，Google Finance `CRSPTM1:INDEXNASDAQ` 的近期日度 OHLC 作同日对照。`price_sources = ["yahoo", "google"]`，不设置 `official_price_source`。它遵循非官方价格的核验门槛：没有对照或差异超过5%时，EPS/band 留空，不能因采用 ETF 代理而放宽。旧 `index_price_only_v1` 历史独立保留。

Google 适配器只解析公开 HTML 中 JSON 格式的数据数组，验证价格指数身份、日度周期、纽约时区以及已收盘日期；不执行脚本、不依赖 Google CLI、账号或浏览器。公开页面只提供近期日线，范围之外保持缺口。两种分发渠道可能共享上游，不将来源对照称为独立指数重算。详见 [VTI 接入记录](vti-proxy-2026-10-16.md)。CSV 字段 `history_frequency`、`pe_usable` 明确统计采样与派生资格。

## 本地运行与验证

```bash
uv run index-valuation backfill-index --index csi300
uv run index-valuation serve
uv run pytest
uv run alembic check
```

网页交互验证使用 Playwright WebKit，不使用 Google Chrome：

```bash
PLAYWRIGHT_BROWSERS_PATH="$PWD/.cache/playwright" uv run playwright install webkit
PLAYWRIGHT_BROWSERS_PATH="$PWD/.cache/playwright" uv run python scripts/check_web.py
```
