# 指数现状总结

入口为[估值页面顶部](http://127.0.0.1:8000/#market-overview)。全部配置指数按各自当前方法的最新入库日期展示，点击指数可查看其详细估值图。每项保留真实数据日期、PE 和判定依据；不将不同市场的数据都标成北京时间当天。

## 两条线与灯号

| 灯号 | 状态 | 页面行动提示 | 条件 |
| --- | --- | --- | --- |
| 绿色 | 恐慌 | 持续买入 | 当日有效 PE ≤ 恐慌线 P10 |
| 黄色 | 普通 | 继续持有 | P10 < 当日有效 PE < P90 |
| 红色 | 贪婪 | 减仓离场 | 当日有效 PE ≥ 贪婪线 P90 |
| 灰色 | 暂无判断 | 显示具体原因 | 暂停采集、当日 PE 缺失或不可用、历史不足、尚未计算或阈值无法区分 |

行动文案为用户指定的估值规则展示。P10 与 P90 使用估值日 D 之前5年的同一批有效正 PE，区间为 `[D−5年, D)`，排除当天、未来和发布前回溯数据；仅使用同一方法、来源和口径，沿用现有 PE 可用性规则。须同时满足5年历史跨度和指数配置的最少观测数，不能用更短历史冒充完整窗口。两阈值相等时不强行选绿或红。

日度来源按观测日取样；周度来源按已结束自然周的最后有效值取样。两条线分别使用独立版本 `rolling_pe_p10_v1`、`rolling_pe_p90_v1`，同一轮计算产生，全部数值计算使用 `Decimal`。来源会计口径的未核实状态保留，不因计算了分位而变成已独立核验。

## 当前总览与历史图表

顶部总览显示最新入库记录，不随下方估值日期、展示区间或普通 band 统计窗口变化。最新日期没有有效 PE 时显示灰色，不退回上一条有 PE 的日期给出当前灯号；暂停采集指数也不对旧记录亮三色灯。页面刷新仅读取本地数据。

图表中恐慌线为绿色、贪婪线为红色。PE 模式画当日两条 PE 阈值；点位模式画当日有效隐含 EPS 乘对应阈值的水平线。EPS 缺失时保留 PE 线并留空点位线，不借其他日期 EPS。历史回看使用历史当日的两条线，不套用今天的阈值。

## 更新与验证

每日增量、回填和 `build-index` 都通过同一派生流程重算并保存两条线及灯号；历史输入修订后会重算受影响的后续日期。现有指数首次启用贪婪线时，仅从已入库数据执行 `build-index`；暂停采集的指数不重建旧方法，不请求外部来源。

只读接口 `/api/market-overview` 提供最新总览；各指数 dashboard 提供所选日 `panic_line`、`greed_line`，CSV 保留相应阈值、点位、状态、日期、版本及样本字段。已有历史研究归档不参与灯号计算。

验证覆盖阈值边界、同源同方法、无前视、日周频、历史修订、暂停与缺失值，以及数据库持久化和 API/CSV 一致性。网页通过 Playwright WebKit 核对双线颜色、单位、历史回看、总览指数切换及手机布局：

```bash
make test
make test-db
PLAYWRIGHT_BROWSERS_PATH="$PWD/.cache/playwright" uv run --locked python scripts/check_market_overview_web.py
PLAYWRIGHT_BROWSERS_PATH="$PWD/.cache/playwright" uv run --locked python scripts/check_web.py
```
