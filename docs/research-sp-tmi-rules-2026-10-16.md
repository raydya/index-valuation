# S&P Total Market Index 规则核验

核验日期：2026-10-16。仅研究，无生产配置、数据库或授权变更。

来源：[S&P U.S. Indices Methodology，2026 年 7 月](https://www.spglobal.com/spdji/en/documents/methodologies/methodology-sp-us-indices.pdf)。下列页码为文档印刷页码；PDF 阅读器页数需加 1。

| 事项 | TMI 规则与定位 |
| --- | --- |
| 范围、权重 | 全部合资格美国普通股，自由流通市值加权；无固定成分数（p.4、12） |
| 身份 | 美国注册地认定；满足美国本土发行人定期申报要求；合资格美国交易所上市，排除 OTC（p.7） |
| 证券类型 | 普通股及股权、抵押 REIT 可入；排除 BDC、LP/MLP、ETF、ADR、未完成合并的 SPAC 等；tracking stock 可入（p.7–8） |
| 最低市值 | 无最低市值要求（p.8） |
| 自由流通 | 新成分 IWF≥0.10；或其自由流通市值≥TMI 第100大公司总市值的10%。既有成分无最低要求（p.8–9） |
| 流动性 | 新成分 FALR≥0.1，即年成交金额/自由流通市值；不足一年交易记录会年化。既有成分无最低要求（p.9） |
| 盈利 | 无盈利筛选；不能套用 S&P1500 的最近季度及四季度累计正盈利要求（p.9） |
| 完整重构 | 每年9月第三个周五收盘后；资格参考日为生效日前五周（p.12、17） |
| 季度维护 | 季度再平衡考虑 IPO、转板、退出破产、国籍或证券类型变更等；不重新筛选现有成分。此前因流动性或 IWF 不足而落选者等下一次年度重构（p.12、17） |
| IPO | 普通 IPO 等季度纳入；大型 IPO 自由流通市值至少20亿美元，可豁免流动性筛选走快速纳入，公告后至少五个工作日实施（p.10） |
| 历史 | 发布日2006-03-27；首个历史值2004-12-31；基日2005-05-31、基点1200（p.19） |
| 代码 | Bloomberg `SPTMI`，Reuters `.SPTMI`（p.25）；均需与实际接口证券身份及回报版本交叉核实 |

原文短证据：p.8 “No minimum market capitalization requirement”；p.9 “No financial viability requirement”；p.17 “reconstituted annually”。

用于 VTI 基准比较时，应突出小微盘准入、流通股处理和纳入时间差异。两者同属全市场市值加权，不代表成分完全相同，也不证明 PE 计算方法相同。不得把 S&P1500 的市值、盈利或12个月 IPO 观察期误套给 TMI。

另有 `S&P Composite 1500 / S&P TMI (Spliced as of EOD Dec-18-2015)` 拼接指数：2015-12-18 前采用 S&P1500，之后采用 TMI（p.5、48）。若使用 ETF 历史基准，须另查发行人说明，避免把拼接业绩当作全期纯 TMI 历史。
