# 指数估值网页设计

核心工作是先查看全部指数现状，再比较实际指数点位与各 PE 倍数对应点位，并能回看任一交易日。顶部提供紧凑的指数现状总结，之后是宽幅估值带图及所选日期的倍数点位表，底部提供历史日表和数据来源。

配色：画布 #F3F6FA、纸面 #FFFFFF、正文 #20304A、主线 #244BC5、低倍数 #258C88、高倍数 #B47628。估值带使用少量半透明蓝绿层次，实际点位使用深蓝实线。差异提示使用琥珀色，并辅以文字，不能只靠颜色判断。

字体：中文使用系统苹方 / 微软雅黑，数字使用系统无衬线及等宽数字特性；不依赖外部字体请求。标题 26px，核心数据 28px，正文 14px，辅助说明 12px。

布局（左对齐）：

```text
指数选择                  数据截至日期 / 导出
[ 全部指数现状：按市场分组，灯号、行动、PE、日期 ]
名称、报价、PE、隐含EPS、历史分位
历史区间 / 图表模式 / 日期选择
[             估值带主图             ][倍数点位表]
[      投资定时任务：计划、执行状态、结果与缺口      ]
[      历史数据表、分页、来源核验                 ]
```

审视：不使用每项一张卡片的通用仪表盘布局。数字集中在一条摘要栏，主图及倍数点位表共享同一工作区。Band 表的各行颜色与曲线一致；切换日期同时更新摘要、表格和图中选中标记。手机端改为上下排列，表格允许横向滚动。

数据语义：富途指数 PE 与中证滚动 PE 单列；隐含 EPS 的单位为指数点，不声称 TTM 已核实。分位只使用所选日期之前同一来源的正 PE，回溯数据与正式发布后数据分开标记。缺失不连成有效数据，导出包含来源和质量状态。

指数现状：沿用白色纸面、蓝灰文字及系统字体，按内地、香港、美国排列紧凑列表，不为每个指数创建一张独立卡片。恐慌绿灯 #18875B、普通黄灯 #B07B12、贪婪红灯 #C44336，分别对应「恐慌，持续买入」「普通，继续持有」「贪婪，减仓离场」；灰灯明确显示暂无判断及缺失、短历史或暂停原因。判断直接读取后端结果，不用前端浮点数或四舍五入后的 PE 再分类。各项同时显示实际数据日期及 PE，可点击或用键盘选取指数。通过独立的 `/api/market-overview` 读取最新状态，历史回看不改变总览；每分钟及手动刷新均仅读取，失败保留旧记录并标记过期。

双估值线：同一方法、同一来源口径、所选日期之前5年的 P10 为绿色恐慌线，P90 为红色贪婪线。图表显示所选日的两条水平参考线，PE 模式使用阈值，点位模式使用该日有效隐含 EPS × 阈值；缺少 EPS 时不绘点位线。纵轴同时容纳两条线，标签避免重叠及超出绘图区。下方共用一个滚动估值线面板，分别展示阈值、对应点位、距离与样本；历史日期读取当日线，图表区间及常规统计窗口不改变5年规则。

定时任务位于估值图之后，顶部「定时任务」入口可直接跳转。复用蓝灰配色与系统字体，以对齐的列表行呈现任务、每日计划、调度状态、最近执行和下次计划；展开行后再展示排队/开始/结束时间、执行摘要、数据覆盖、缺口及结果原文。手机端每行改为分组标签，数据覆盖表仅在自身容器内横向滚动，不使用五张独立卡片。

任务状态始终反映最近读取的当前记录，与指数选择及历史估值日期独立。明确区分调度启用、已排队、执行中、部分完成与已返回结果；返回结果不等同于数据全部成功。数据日期与核验 / 完整截至日分列；后者对指数表示具备 EPS 计算条件的日期，对表格项表示已核验输入日期，未知日期不补齐。页面可见时每分钟读取 `/api/scheduled-tasks`，手动刷新也只读状态；失败时保留前次记录并标记过期，避免影响图表使用。后端所有文本按纯文本显示，执行结果原文保留换行，不渲染为 HTML。
