# 指数估值网页设计

核心工作是比较实际指数点位与各 PE 倍数对应点位，并能回看任一交易日。首屏以宽幅估值带图为主体；右侧是所选日期的倍数点位表，底部提供历史日表和数据来源。

配色：画布 #F3F6FA、纸面 #FFFFFF、正文 #20304A、主线 #244BC5、低倍数 #258C88、高倍数 #B47628。估值带使用少量半透明蓝绿层次，实际点位使用深蓝实线。差异提示使用琥珀色，并辅以文字，不能只靠颜色判断。

字体：中文使用系统苹方 / 微软雅黑，数字使用系统无衬线及等宽数字特性；不依赖外部字体请求。标题 26px，核心数据 28px，正文 14px，辅助说明 12px。

布局（左对齐）：

```text
指数选择                  数据截至日期 / 导出
名称、报价、PE、隐含EPS、历史分位
历史区间 / 图表模式 / 日期选择
[             估值带主图             ][倍数点位表]
[      投资定时任务：计划、执行状态、结果与缺口      ]
[      历史数据表、分页、来源核验                 ]
```

审视：不使用每项一张卡片的通用仪表盘布局。数字集中在一条摘要栏，主图及倍数点位表共享同一工作区。Band 表的各行颜色与曲线一致；切换日期同时更新摘要、表格和图中选中标记。手机端改为上下排列，表格允许横向滚动。

数据语义：富途指数 PE 与中证滚动 PE 单列；隐含 EPS 的单位为指数点，不声称 TTM 已核实。分位只使用所选日期之前同一来源的正 PE，回溯数据与正式发布后数据分开标记。缺失不连成有效数据，导出包含来源和质量状态。

定时任务：保留主图为首屏主体，顶部「定时任务」入口跳转到主图后的任务列表。复用蓝灰配色与系统字体，以对齐的列表行呈现任务、每日计划、调度状态、最近执行和下次计划；展开行后再展示排队/开始/结束时间、执行摘要、数据覆盖、缺口及结果原文。手机端每行改为分组标签，数据覆盖表仅在自身容器内横向滚动，不使用五张独立卡片。

任务状态始终反映最近读取的当前记录，与指数选择及历史估值日期独立。明确区分调度启用、已排队、执行中、部分完成与已返回结果；返回结果不等同于数据全部成功。数据日期与核验 / 完整截至日分列；后者对指数表示具备 EPS 计算条件的日期，对表格项表示已核验输入日期，未知日期不补齐。页面可见时每分钟读取 `/api/scheduled-tasks`，手动刷新也只读状态；失败时保留前次记录并标记过期，避免影响图表使用。后端所有文本按纯文本显示，执行结果原文保留换行，不渲染为 HTML。
