# 沪深300直接估值与网页上线记录

采集日：2026-10-13。以富途指数 PE 为主，直接计算指数隐含 EPS 和 PE band，保留三方价格核验及独立的中证滚动 PE 对照。不依赖历史成分股权重。

本机网页：http://127.0.0.1:8000 。服务由 `uv run index-valuation serve` 启动；PostgreSQL 需保持可访问。

本次请求发现42条非交易日记录，保留原始响应并隔离。范围探测中的中证 `19900101` 占位记录未作为有效历史起点；最早有效日为2002-01-04。

## 网页能力

- 固定 PE 倍数带、滚动历史分位带、PE 历史走势。
- 1/3/5/10年及全部图表区间；3/5/10年及全部历史分位窗口。
- 按日期回看、键盘左右查看图表、逐日数据分页、选定区间 CSV 下载。
- 桌面与手机布局；显示 PB、PS、价格来源、PE 来源差异及数据缺口。
- 索引配置驱动，新增同类指数可复用采集、计算和网页，无独立的沪深300算法分支。

旧的21:00与22:00定时任务仍调用 `scripts/run_scheduled.py`，其入口已改为 `update-index --all`，不再要求300只成分股全部可用。执行时重抓最后已入库日之前14天至最新收盘的历史序列；全量重抓使用 `backfill-index`。

已实际试跑 `update-index --index csi300`（任务 `9656e5d7-047a-4d27-a399-ee31042caf2f`），采集区间2026-09-29至2026-10-13，全部来源请求成功；重复派生后仍为6,007个交易日、5,286条隐含 EPS，没有重复入库。
