## 11 个近期交易日的精度检查

对每只 ETF 的 11 个近期日 K，使用固定的报表分母，逐日以当天收盘价重建两类 PE。结果为每组 9/11 在六位小数完全相同，其余 2/11 仅差 0.000001；四组合计 **36/44 完全相同，44/44 的差异不超过六位小数末位 1 个单位**。

因此不能写成“所有近期日期逐位完全相同”。接口数值精度或上游输入处理可解释这种量级的差异，但本次没有获得供应商的舍入规范，未将该解释视为已确认事实。作为单独校验，将 VTI 重建的 2024 分母截断为其先前公开网页返回的 `ttmEps=41.758587` 后，11/11 个 `ttmPe` 均匹配六位小数；其他组没有为匹配目标值调整财务输入。

特别是 `ttmPe` 的数值对应 2024 全年，而 `lyrPe` 对应 2025 全年，不能仅凭字段名字就将前者宣称为截至 2026 年最近十二个月的盈利。未验证每个历史日期的财报可得时点、修订情况及全历史算法连续性。

复算示例：

```python
from decimal import Decimal, getcontext

getcontext().prec = 40
fund_operations = Decimal("346153203000")  # VTI 2024 全基金运营损益
all_class_shares = sum(
    [
        156979031,
        1575749087,
        2884702340,
        671491558,
        2700130705,
        300336869,
    ]
)
reconstructed_denominator = fund_operations / all_class_shares
pe = Decimal("378.42") / reconstructed_denominator
assert pe.quantize(Decimal("0.000001")) == Decimal("9.062088")
```

## 对项目的处理

此次消除了“仅因 PE 看起来较低就拒绝”的不确定性：VTI、VOO 的 API 字段与发行人基金会计报表能够复算对应。它们包含基金投资价格涨跌，并涉及不同净值份额类别的直接合计；这与项目所需的指数或持仓公司盈利估值含义不一致。保留为研究证据，不导入生产指数 EPS、PE band 或恐慌线。

若继续向 Tiger 核实，应携带以上证券、日期、字段与复算式，询问是否另有持仓穿透 PE、指数 PE 或归一化份额口径，并确认历史修订与财报可得日期。尚未联系供应商，也未宣称已得到其算法确认。
