## 官方价格接口核查

Nasdaq 公共历史接口对 `CRSPTM1` 未返回可用日线。[Morningstar 官方指数页](https://indexes.morningstar.com/indexes/details/morningstar-us-total-market-FS00009VTK)可确认价格回报版本的 `secId=F00000P7NM`，但对应近期价格接口返回空数组；详情请求虽标为 PR，却返回与 TR 页面相同的7153.503点，不能确认为所需价格回报系列，因此未入库为 PR 点位。没有因官方标签而将全收益数值代入价格指数。

核查原始响应保存在 `data/raw/vti_proxy_probe/`。Google 的读取通过普通公开 HTTP 页面完成，无 Google CLI、账号凭据或 Chrome 依赖。

## 方法与边界

配置：`valuation_source=yahooetf`、`yahoo_proxy_symbol=VTI`、`price_sources=[yahoo, google]`，不设置官方价格主源。新方法为 `yahoo_vti_proxy_yahoo_google_daily_v1`；旧价格专用方法和导出保留。计算继续使用 `Decimal`：

```text
代理隐含 EPS = 同日指数收盘点位 / Yahoo VTI 代理 PE
倍数参考点位 = 代理隐含 EPS × 指定 PE 倍数
```

非官方点位必须有同日第二来源，差异≤1%通过、1%—5%警告、>5%阻断派生。缺对照时仍保存价格和 PE，但不计算 EPS/band。官方主源的标普500、纳指100规则保持不变。

Google 适配器验证指数代码、PR/USD 名称、86400秒日度周期、已收盘时间、纽约时区以及重复日期。仅解析 JSON 数据数组，不执行页面 JavaScript；实时报价、折线图点、周线或月线不得当作日收盘。页面近期窗口之外不补值，不宣称提供完整历史。

Yahoo PE 仅提供当前快照，逐日采集，不回填到旧日期；首次只有一个估值日期，所以8倍等固定参考值显示为当日点，不能称为完整历史 band。均值和分位需至少252个先前观测。旧恐慌研究中“缺少 PE”仍是当时记录；当前已有代理 PE 时，页面比较状态显示历史样本不足，不凭单个快照生成恐慌线。
