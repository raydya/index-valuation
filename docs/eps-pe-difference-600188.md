## 利润归属口径

富途财务接口 `get_financials_statements` 的字段3047（母公司所有者净利润）与财报列示的母公司普通股股东利润存在区别。以下金额均为人民币千元：

| 期间 | 富途字段3047 | 财报母公司股东利润 | 其他权益工具持有者利润 |
| --- | ---: | ---: | ---: |
| 2025全年 | 9,008,478 | 8,380,948 | 627,530 |
| 2026上半年 | 7,473,245 | 7,149,644 | 323,601 |
| 2025上半年（比较期） | 5,152,257 | 4,839,084 | 313,173 |

三个期间均有“富途字段3047 = 财报母公司股东利润 + 其他权益工具持有者利润”的关系。年报合并利润表将两类利润分别列示；不能把其他权益工具持有者利润直接分配给普通股。[2025年年报，第155页](https://static.cninfo.com.cn/finalpage/2026-03-28/1225048701.PDF)、[2026年半年报原文](https://vip.stock.finance.sina.com.cn/corp/view/vCB_AllBulletinDetail.php?id=12572743)

以2025全年 + 2026上半年 − 2025上半年计算：

```text
普通股股东口径 TTM 利润 = 10,691,508,000 元
包含其他权益工具利润的 TTM 金额 = 11,329,466,000 元
差额 = 637,958,000 元
```

东方财富当日总股本为10,036,852,020股。用普通股股东口径利润除以总股本得到 EPS 1.0652252299，再用19.71元除以该 EPS 得到 PE 18.5031291483，与 BaoStock、东方财富相符。富途字段3047对应的隐含 EPS 约1.12879，与其历史估值反算 EPS 相近，仍有约0.024%的残差，未进一步归因。

这些证据支持“利润归属口径是主要差异来源”，不支持直接放宽核验阈值。当前仍保留富途原始 PE 及其隐含 EPS，并阻止其作为已核验的普通股盈利进入指数估值。没有将个别案例的调整规则推广到其他股票或全部历史日期。
