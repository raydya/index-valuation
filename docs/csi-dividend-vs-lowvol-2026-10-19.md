# 中证红利与红利低波对比

核验日期：2026-10-19。项目 `divlowvol` 为中证红利低波动指数 **H30269**，50只样本、价格指数；本次对比对象为中证红利 **000922**。研究没有新增指数或修改采集、估值数据。[项目配置](../indices.toml)、[既有接入记录](divlowvol-index-2026-10-13.md)

## 编制规则

两者均以中证全指样本空间为基础，设置市值和流动性门槛，并采用股息率加权。红利低波增加分红增长和低波动筛选，并非直接从中证红利100只样本中挑50只。以下据本次取得的中证官方方案：[000922，2023-12、V1.3](https://oss-ch.csindex.com.cn/static/html/csindex/public/uploads/indices/detail/files/zh_CN/20231208175433-000922_Index_Methodology_cn.pdf)、[H30269，2020-12、V1.1](https://oss-ch.csindex.com.cn/static/html/csindex/public/uploads/indices/detail/files/zh_CN/H30269_Index_Methodology_cn.pdf)。检索未发现两者更新版本的官方方案；版本日期不是数据日期。

| 项目 | 中证红利 000922 | 红利低波 H30269 |
| --- | --- | --- |
| 样本数 | 100 | 50 |
| 规模、流动性 | 过去一年日均总市值、成交金额均处于样本空间前80% | 同样要求前80% |
| 分红门槛 | 连续3年现金分红；3年平均及最近一年股利支付率均在0与1之间 | 连续3年现金分红、每年税后现金股息率为正；剔除最近一年支付率为负或排名最高5%的证券，以及过去3年每股股利增长率非正的证券 |
| 排序选样 | 按3年平均现金股息率选前100 | 先按3年平均税后现金股息率取75，再按过去一年波动率从低到高取50 |
| 加权 | 股息率加权；单股上限10%，总市值低于100亿元的单股上限0.5% | 股息率加权；单股上限15%，并非波动率倒数加权 |
| 定期调样 | 每年12月第二个星期五之后的下一交易日 | 相同 |

调样一般不超过20%；若因最近一年股息率未超过0.5%而剔除的原样本已经超过20%，可以突破。原样本的市值、成交金额资格放宽至前90%；000922还要求3年平均支付率处于0与1之间。H30269在此使用税后股息率。两者权重因子随年度调样更新，其间一般固定，表中上限不是每天重新强制归位的仓位承诺。上述规则来源同两份官方编制方案。

由这些规则和样本快照可作以下解释，但不能外推为永久行业权重或未来收益承诺：红利低波更重视历史股价稳定性，但50只样本和较高的单股上限不意味着更分散；本次金融权重明显更集中。低波动是选股条件，不保证所有区间都比中证红利波动更低，近3年数据即是反例。

## 对本项目估值展示的含义

- 两者行业组成和筛选不同，PE宜各自与同口径历史均值、分位和恐慌线比较；不能仅凭绝对PE更低判定另一指数一定更便宜。这是基于上述组成差异的分析判断，不是对未来回报的验证。
- 项目当前红利低波为价格指数，年化涨幅不含现金分红。评价红利策略完整回报时应另用一致口径的全收益序列；官方单张列出的全收益代码分别为中证红利 **H00922**、红利低波 **H20269**，不应覆盖现有价格指数序列。来源为上述两份官方单张。
- 本文不涉及上证红利000015或红利低波100；名称相近不能替代H30269的身份和规则。
