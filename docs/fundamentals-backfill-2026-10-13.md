# 沪深300个股 EPS TTM / PE 历史回填结果

本轮已对全部300只已知成分公司完成采集、PostgreSQL 入库及核验。区间为 **2005-04-08～2026-10-12**，每只股票从上市日开始检查。这里的300只来自已保存的2026-09-30权重快照，**不是2005年以来历次调样的完整证券集合**。

富途提供个股历史 PE TTM，东方财富提供获授权的未复权历史价格，BaoStock 独立核验价格、PE 和 EPS。EPS 是同日价格 / 富途 PE 得到的**供应商隐含盈利**，不是直接从原始财报重算的基本或稀释 EPS。方法为 `futu_company_pe_ttm_eastmoney_v1`。

EPS 非空覆盖率为97.27%。170条记录有富途 PE、缺补充价格，因此 PE 数量多于 EPS 数量；不会跨日拼凑价格。

| 核验状态 | 日记录数 | 含义 |
| --- | ---: | --- |
| `verified` | 997,388 | 价格、PE、EPS 跨源差异均不超过1% |
| `review` | 33,978 | 至少一项差异超过1%、不超过5% |
| `blocked` | 60,438 | 至少一项差异超过5%，保留候选值，阻止用于指数估值 |
| `missing_price` | 27,397 | 同日未复权价格缺失；全部对应 BaoStock 标记的停牌日 |
| `missing_pe` | 3,235 | 有价格，缺有效的富途 PE；零 PE 不反算 EPS |
| `unverified` | 1 | 中航成飞 `SZ.302132` 的2012-09-10缺 BaoStock 可比 PE |

因此，任务的数据质量状态为 `partial`，不能把109万条候选 EPS 都当作通过核验的数据。已通过核验的记录占全部应检查记录的88.86%。

首轮2只股票（`SZ.002648`、`SZ.002709`）遇到 BaoStock 网络接收异常，均已在续跑中补齐。续跑复用了298只股票的完成进度，最终采集错误数为0。

## 指数计算的实际结果

已使用真实入库记录试算2026-09-30、10-08、10-09、10-12。4天均因信达证券数据缺口和兖矿能源盈利口径差异而返回 `blocked`，不输出指数 EPS / PE。主源必要字段的权重覆盖为99.9390%，仍不通过丢弃缺失股票并重新归一化来生成结果。

2005-04-08 的试算因没有不晚于当日的权重快照而停止。数据库仍只有2026-09-30的权重；无法用当前300只及当前权重重建指数创立以来的实际成分估值，历史 PE band 尚未生成。之前保存的数据商指数 PE 继续独立保留。
